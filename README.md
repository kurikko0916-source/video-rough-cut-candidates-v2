# 粗カットAI

建築・住宅系YouTubeの日本語対談動画を解析するMac用ローカルアプリです。タイムコード付き文字起こしと、任意で実行する保守的な粗カット候補の提案を行います。

## MVPの方針

- 元MP4はコピーせず、Mac上のファイルを読み取り専用で直接参照
- 音声・文字起こしはMac内で処理
- 有料APIは使用しない
- 文字起こし完了後に止めても、結果はMac内に保存される
- ローカルAI判定は別ボタンで任意実行する
- 15秒以上のまとまった不要区間を優先し、最大12件に絞る
- 相づち、単独フィラー、数秒のテンポ調整は原則対象外
- 中心テーマ、主な結論、重要ポイントを判定前に表示
- 粗カット指示は開始・終了・カット後の話し始めの3列でコピー
- 発言のタイムコードから動画を再生できる
- Silero VADは文字起こし後の独立処理として実行し、発話・非発話区間を元動画の時間軸で保存
- VADモデルがない、またはVADが失敗した場合も文字起こし・SRT・JSONは正常完了
- 言い直し・重複テイク・撮影NGサインはローカルのルールと文字列比較だけで確認候補として保存
- ステップ3では意味的重要度を判定せず、数字・専門用語・まとまった追加内容がある候補は「検討候補」へ下げる
- 検出時の元範囲と、VADで境界調整した推奨範囲は別々に保持
- 候補は削除せず、最終判断は必ず人間が行う

## ローカルツール

- 専用Python 3.12
- FFmpeg / ffprobe
- whisper.cpp (`whisper-cli`)
- whisper.cpp VAD (`whisper-vad-speech-segments`、任意)
- Ollama

これらはApple開発ツールを使わず、`tools/` のプロジェクト専用環境に配置します。Mac全体の開発環境は変更しません。

## 起動

`start.command` をダブルクリックします。アプリが起動し、ブラウザーで `http://127.0.0.1:8765` が開きます。文字起こしだけではOllamaを起動せず、粗カット候補を明示的に開始した場合だけローカルOllamaを起動します。

ステップ3の言い直し・重複候補抽出ではOllamaを使いません。文字列上の類似・追加量、撮影NGサイン、発話の未完了らしさを使い、結果をJSONの `take_detection` に追加します。この処理に失敗しても、文字起こし・SRT・VADまでの結果は保存されます。

ローカル画面の「動画を選択」を押すとMac標準のファイル選択画面が開きます。選択したMP4は移動・複製せず、ffprobeとFFmpegが元の場所から直接読み取ります。文字起こし完了後は、Vrew用SRTと、発話単位・whisper.cppの元tokensを含む後続処理用JSONを保存できます。

## Silero VAD（任意）

VADモデルは自動ダウンロードしません。モデルがない場合はVADだけをスキップし、ステップ1の文字起こしを通常どおり完了します。この環境ではwhisper.cpp公式配布の `ggml-silero-v6.2.0.bin` を `models/ggml-silero-v6.2.0.bin` に導入済みです（885,098バイト、SHA-256: `2aa269b785eeb53a82983a20501ddf7c1d9c48e33ab63a41391ac6c9f7fb6987`）。VADは同じ16kHz WAVを独立して解析し、`segments`、`tokens`、SRTを変更しません。

15GB級の素材をCloud版で使う場合は、`高速文字起こし.command` をダブルクリックします。操作は同じくMP4を選ぶだけですが、Mac内で音声へ縮小し、数十MBの音声だけをCloud Runへ送ります。

whisper.cppのモデルを `models/ggml-large-v3-turbo-q5_0.bin` に置くか、環境変数 `WHISPER_MODEL` で指定します。Ollamaのモデル名は `OLLAMA_MODEL` で変更できます（初期値: `qwen3:4b`）。

解析中の一時ファイルと結果は `data/jobs/` へ保存され、GitHubには送られません。

## GitHubと実行時データ

- ソースコードと更新頻度の低い設定JSONはGitHubのPrivateリポジトリへ保存します。
- `config/*.json` はビルド時にコンテナへ同梱するため、通常閲覧時にGitHub APIを呼びません。
- 動画・文字起こし・解析結果は容量と機密性の理由からGitHubへ保存せず、ローカルまたはCloud Storageへ保存します。
- 通常の初期表示では前回結果を自動取得しません。`?job=...` を含む結果URLを開いた場合だけ保存済み結果を取得します。

## 将来拡張の入れ物

`config/channel_rules.json` に、将来のチャンネル固有ルール・残す例・カット例を分離して追加できる構造を用意しています。MVPでは無効です。
